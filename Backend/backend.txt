Features Implemented

1. Connected LeetCode Profile API to Node.js Backend
   - Created Express server using ES Modules
   - Configured routes and controllers
   - Connected backend to LeetCode GraphQL API using Axios
   - Dynamically fetches profile data using username parameter

   Endpoint:
   GET /api/leetcode/:username

   Example:
   GET /api/leetcode/Sp80rz8mxi

2. Fetch LeetCode Profile Details
   - Username
   - Ranking
   - Reputation
   - Solved Problems Statistics
     • Easy
     • Medium
     • Hard

3. Implemented HTTP GET Method
   - Client sends request through Postman
   - Backend fetches data from LeetCode GraphQL API
   - Returns structured JSON response
